Climbing the Ladder of Abstraction conference talk
How do we review an endless stream of agent work? On reviewing AI-generated work: how the human moves up the abstraction hierarchy - from making to reviewing - as coding agents take the lower rungs. Opens on Hayakawa's ladder of abstraction, then: the spectrum → a review problem → not just code → the methods → close.

The Lethal Trifecta talk
Using AI agents safely when they can reach your stuff. The structural risk when an agent holds all three of private data, untrusted content and a way to act - and how to stay safe by construction: cut a leg per task, and never run all three unattended. Runs the prize → the worry → the freeze → the principles → a morning-briefing case study → what it means for you.
