## What this is

A plain static site (HTML, one CSS file, one small JS file, no framework, no build step needed to serve it). Every page is a complete HTML file, so the folder can be dropped onto any static host, or ported into whatever repo serves paidiaconsulting.com today.

It follows Nikki's design study (`paidia-design-study.unthank.chatgpt.site`, made with ChatGPT/Codex): Playfair Display and Inter, forest green on warm paper, lime accent, the highlands painting in the hero. On top of that it applies the changes from `Competitor Analysis/2026_10_24 - AI consultancy landscape and positioning.md` (website section).

## Workshop format

The workshop page follows `Market Research/2026_10_24 - Workshop format - half day or three weekly hours.md`: a 30-minute online set-up call a week before, one 3.5-hour afternoon in person, and two 45-minute online follow-ups at one and three weeks, with a chat group for 30 days.
