# Paidia site redesign (review build, October 2026)

A review build of the paidiaconsulting.com site, not yet live. Plain static HTML in `site/`,
generated by the Python scripts in `build/` (edit `build/content.py` and `build/workshop.py`,
then run `python3 build/build.py`, which writes into `site/`).

Read `site/README.md` first: it is the dated log of every change, what still waits on David
and Nikki (booking tool, which entity invoices, the second session date, the hero image), and
the generator rules. The research behind the build lives in the shared Papperlapapp Drive folder
under `Projects/Paidia website redesign/` (`review/`, `review-2/`, `review-3/`).

To promote it to the live site: copy the contents of `site/` to the repository root (the pages,
`assets/site.css`, `assets/site.js`, `assets/clients/`, `assets/team/` and the painting files),
keep `privacy.html`, `presentations/`, `files/`, `msg/`, `rz/` and `server/` as they are, and
delete the old root `index.html` and `assets/images/` if nothing else uses them. `expertise.html`
should redirect to `services.html`.

Workshop first cohort: Friday 20 November 2026, £499 + VAT. The welcome email draft for people who
book is in `docs/`.
